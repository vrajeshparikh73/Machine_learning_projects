# Individual Diabetic Retinopathy Detection
This individual computer vision project focuses on addressing diabetic retinopathy, the leading cause of blindness among working-age adults, which often goes undetected in its early stages due to a severe shortage of rural eye care specialists. To bridge this health equity gap, I built an automated screening pipeline that processes retinal fundus photographs to flag early disease presence. By leveraging deep learning, my goal was to provide non-specialist primary care clinics with a fast, accessible diagnostic triage tool that can reliably detect silent micro-lesions and refer high-risk patients for urgent care before permanent vision loss occurs.

To accomplish this, I designed and trained a custom Convolutional Neural Network (CNN) architecture in Python using deep learning frameworks. The pipeline uses sequential 2D convolutional layers with small filters to automatically extract spatial biomarkers such as microaneurysms, hemorrhages, and hard exudates from fundus images. These extracted features pass through non-linear activation functions and max-pooling layers for spatial downsampling before deep dense layers aggregate the signals into a final classification output. I then validated the model's performance with a strong emphasis on high recall and sensitivity to minimize false negatives, ensuring maximum reliability in clinical screening scenarios.

# Hypothyroidism Project Details
This project focuses on hypothyroidism, a condition where an underactive thyroid gland fails to produce enough essential hormones. By applying machine learning to clinical patient data, we can accurately predict disease presence, classify specific diagnostic types, and estimate continuous TSH levels. The project challenges us to train and evaluate multiple models (binary classification, multiclass classification, and regression) to determine the most reliable architecture while identifying key clinical features to optimize diagnostic efficiency.

# Sleep analysis Project Details
This project focuses on automated sleep stage classification (Awake, NREM1–3, and REM) using physiological signal segments from MGH's CCNL/CDAC sleep database. Because raw time-series signals like EEG and ECG are noisy, we apply the Fourier Transform to convert signals from the time domain into the frequency domain, extracting key spectral features (such as delta, alpha, and beta wave power bands). The project challenges us to build, train, and evaluate deep learning and machine learning models (in PyTorch and Scikit-Learn) to accurately predict sleep and arousal states.
